# Codex Chat

Codex Chat is a desktop-only Obsidian plugin that adds a Codex-powered chat sidebar with vault context, `@` references, PDF text extraction, local Codex CLI fallback, session history, and shared `_agent` memory.

The plugin is designed for desktop vaults. Mobile is intentionally unsupported in this release because local fallback uses Node.js and the Codex CLI.

## Installation

Clone or copy this repository into your vault:

```text
.obsidian/plugins/codex-chat/
```

The installable files are:

```text
main.js
styles.css
manifest.json
README.md
lib/
scripts/
```

Enable `Codex Chat` from Obsidian community plugins. The plugin creates its own local `data.json` on first run.

## Requirements

- Obsidian `1.8.0` or newer.
- Obsidian desktop.
- Codex CLI installed and authenticated with ChatGPT if local fallback is used.
- Optional backend URL if you run a backend under your control.

## Vault Data

`_agent/` is vault data, not plugin source. It stores shared memory, sessions, memory candidates, outbox data, and backups generated by the plugin.

Do not commit or publish:

- `data.json`
- `_agent/`
- `.obsidian/`
- local runtime folders
- backend runtime files
- tokens, secrets, logs, sessions, or vault content

## Safety Notes

- `Planificador / Copiloto` is the safe planning mode. It should read, analyze, summarize, and propose without modifying vault files unless the user clearly asks.
- `Ejecutar / Sin restricciones` can act without additional confirmation. File edits and deletions must create backups first.
- Folder-wide context only uses roots explicitly configured in the plugin settings.
- Technical folders such as `node_modules`, `.git`, `.obsidian`, `_agent`, `dist`, `build`, `.cache`, `.vite`, and `coverage` are ignored as context sources.

## Development

`lib/` contains the maintainable CommonJS source modules. Obsidian loads `main.js`, so `main.js` is generated as a self-contained runtime.

After changing files in `lib/`, run:

```bash
node scripts/bundle-main.js
```

Then copy the plugin files to `.obsidian/plugins/codex-chat/` and restart Obsidian.
